# 🧱 Construccion

{% hint style="success" %}
Usa esta guia y cualquier otra duda que tengas, hazla llegar a un admin para agregar nueva info.
{% endhint %}

Adjuntaremos un video el cual consideramos que se entendera mucho mejor que si lo explicaramos por escrito, lo que si les informamos es que  algunos de los implementos para la construccion los compran en el Trader General y los demas les tocara lootearlos por el mapa. Las bolsas de pegamento y cemento podran encontrarlas en cualquier zona industrial.

{% embed url="https://www.youtube.com/watch?v=DE2qoX1kFtc" %}

Finalmente, los Airdrops de construccion traeran dentro items y complementos que podran servirte mucho para la construccion de tu base.

Si viste el video y aun asi requieres ayuda para entender como funciona, solicita la ayuda de un admin para terminar de comprender el funcionamiento.
