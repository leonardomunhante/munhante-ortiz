# 📒 Bases

{% hint style="danger" %}
Lee este reglamento con responsabilidad y seriedad, luego no digas que no te advertimos.
{% endhint %}

{% stepper %}
{% step %}
#### Primera

Las bases construidas en zonas PVE estan protegidas contra ataques de otros jugadores. Esto brinda un espacio seguro para la cooperacion y la interaccion social.
{% endstep %}

{% step %}
#### Segunda

Las bases construidas deben mantener una distancia minima de las zonas militares (bases militares y puestos de avanzada), la distancia se establece en 500 metros de cualquier zona militar.
{% endstep %}

{% step %}
#### Tercera

Las bases solo podran ser construidas en un maximo de (4 paredes de ancho por 4 paredes de largo) y solo podran tener una altura maximo de (3 pisos), las bases pueden ser construidas en cualquier lugar que tenga acceso a pie, esto descarta ubicaciones con escaleras de mano y zonas acuaticas.
{% endstep %}

{% step %}
#### Cuarta

El equipo de administracion se reserva el derecho de supervisar y evaluar la ubicacion de las bases. Si una base se considera en violacion de las normas, los jugadores podrian recibir un aviso y se les dara un plazo para la correccion, "solicita la visita de un admin para la inspeccion de tu base si lo deseas", nosotros estamos para asesorarlos tambien.
{% endstep %}

{% step %}
#### Quinta

Las bases en zonas PVP y PVE, tienen permitidas como maximo 8 seguros de puerta, esto  incluye codelocks, cadenas de 4 digitos o cadenas de 3 digitos, el incumplimiento de esta regla nos autoriza eliminar todo lo que protega el NOVENO (9) seguro de puerta.
{% endstep %}

{% step %}
#### Sexta

Las bases solo podran tener un maximo de 6 vehiculos desplegados, los demas deberan estar guardados en los garajes virtuales, esta regla no tiene compasion alguna, el septimo vehiculo sera eliminado sin aviso previo.
{% endstep %}

{% step %}
#### Septima

Queda totalmente prohibido colocarle seguros a las cajas, contenedores o armarios, los seguros solo son para las puertas, no habran advertencias previas a la eliminacion de cualquier contenedor con seguro.
{% endstep %}
{% endstepper %}
