# 📗 General

{% hint style="danger" %}
Lee este reglamento con responsabilidad y seriedad, luego no digas que no te advertimos.
{% endhint %}

{% stepper %}
{% step %}
#### Primera

En BOZZ queremos promover una experiencia pvp con la inclusion de zonas pve para fomentar la construccion de bases y ofrecer un equilibrio entre la cooperacion y la competencia.
{% endstep %}

{% step %}
#### Segunda

Estan en la obligacion de mantener un comportamiento respetuoso y evitar el lenguaje ofensivo o discriminatorio en el chat y la comunicacion por voz.
{% endstep %}

{% step %}
#### Tercera

Queda estrictamente prohibido el uso de cualquier tipo de trampas, hacks, exploits, bugs o dupeos, por lo consiguiente los jugadores que sean atrapados haciendo uso de estas mariconadas seran sancionados de manera inmediata y permanente.
{% endstep %}

{% step %}
#### Cuarta

Las violaciones a nuestro reglamento resultaran en sanciones proporcionales a la gravedad de la infraccion. Esto puede incluir advertencias, suspenciones temporales o la expulsion permanente del servidor.
{% endstep %}

{% step %}
#### Quinta

El servidor cuenta con un equipo de administracion para hacer cumplir las reglas y garantizar una experiencia justa para todos los jugadores, AQUI NO EXISTE EL ADMIN ABUSE!.
{% endstep %}

{% step %}
#### Sexta

En caso de disputas, reclamos o denuncias de cualquier tipo, se espera que los jugadores involucrados presenten pruebas adecuadas para respaldar sus afirmaciones. Esto incluye capturas de pantalla, videos u otros medios que puedan verificar los eventos en cuestion.
{% endstep %}

{% step %}
#### Septima

Las zonas de TRADEO y comercio como "Trader General, Trader de Caza, Trader de Helis y Black Market, no pueden ser campeadas bajo ninguna circunstancia y tampoco pueden colocar explosivos o trampas a sus alrededores (rango promedio: 2000 metros).
{% endstep %}
{% endstepper %}
