# 📘 Pve

{% hint style="danger" %}
Lee este reglamento con responsabilidad y seriedad, luego no digas que no te advertimos.
{% endhint %}

{% stepper %}
{% step %}
#### Primera

Algunas areas del mapa han sido designadas como PVE, en donde los enfrentamientos entre jugadores estan totalmente prohibidos ya que el daño tiene rebote, eso quiere decir que si intentas hacerle daño a alguien, el daño lo recibiras tu.
{% endstep %}

{% step %}
#### Segunda

Queda totalmente prohibido el robo de vehiculos que se encuentren en "Trader General", asi como tambien el intento de empujarlos, abrirlos o golpearlos, esto conllevara a una kill instantanea y el borrado de tu personaje sin opcion a reclamos o aclaraciones.
{% endstep %}

{% step %}
#### Tercera

Queda totalmente prohibido el hostigamiento a jugadores en "Trader General", esta zona es para un comercio sano, por lo consiguiente, jugador que moleste, intente robar o extraiga pertenencias de otro jugador tambien recibira una kill instantanea y el borrado de su personaje sin opcion a reclamos o aclaraciones.
{% endstep %}

{% step %}
#### Cuarta

En las zonas PVE los vehiculos pueden ser robados siempre y cuando se encuentren fuera de las bases y sin propietario en las proximidades. (si no puedes robar un vehiculo queda totalmente prohibido destruirlo).
{% endstep %}

{% step %}
#### Quinta

Los clanes solo podran tener un maximo de 6 integrantes, no podran exceder ese limite, de lo contrario se le hara kill instantanea a un miembro al azar y el borrado de su personaje sin opcion a reclamos o aclaraciones.
{% endstep %}

{% step %}
#### Sexta

Las bases en zona PVE son intocables, no intentes abrirlas, no intentes treparlas, no intentes aterrizar sobre ellas, cualquier a de estas acciones sera un  BAN PERMANENTE, no seas tonto y evitate una sancion innecesaria.
{% endstep %}
{% endstepper %}
